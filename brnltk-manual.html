Overview

brnltk (Bangla Regional NLTK) is a modular, training-free Python toolkit designed for processing Bangla regional dialects. Built on top of the PritomBangla human-verified dataset, it combines rule-based linguistics, N-gram statistical matching, and a BiLSTM neural model to cover five major dialect regions.

🌐

Dialect Translator

Convert text between any two Bangla dialect regions using N-gram similarity and word mapping.

from brnltk import translate
🏷

POS Tagger

BiLSTM-powered Part-of-Speech tagging with dictionary fallback for all five dialects.

from brnltk import run_pos_tagger
✂

Stemmer

Rule-based suffix stripping to reduce Bangla words to their root canonical form.

from brnltk import stem_sentence
◉

Tokenizer

Regex-based word and sentence tokenizer that preserves Bangla-specific punctuation.

from brnltk import word_tokenize
Zero-training design All modules work out-of-the-box — no training data or model fine-tuning required. The POS tagger ships with a pre-trained BiLSTM model for each dialect.

Dialect Translator

The translate() function converts a Bangla sentence from one dialect region to another. It uses N-gram similarity to find matching words in the source dialect, then maps them to the target dialect via the PritomBangla dataset.

Signature

PYTHON
from brnltk import translate

result = translate(
    sentence="আমি ভাত খাই",
    from_area="General",
    to_area="Chittagong"
)

Parameters

sentencestrInput Bangla text to translate
from_areastrSource dialect key (see dialect map below)
to_areastrTarget dialect key

Full Example

PYTHON
from brnltk import translate

original   = "আমি ভাত খাই"
translated = translate(
    sentence=original,
    from_area="General",
    to_area="Chittagong"
)

print("Original:  ", original)
print("Translated:", translated)
output
Original: আমি ভাত খাই
Translated: আঁই ভাত হাই

Translate Between Non-Standard Dialects

PYTHON
# Barishal → Sylhet (dialect-to-dialect, not via General)
result = translate(
    sentence="তুমি কই যাও",
    from_area="Barishal",
    to_area="Sylhet"
)
print(result)
💡 Tip — Best Translation Accuracy Use "General" as the source dialect when translating from Standard Colloquial Bangla (SCB). Mymensingh and Barishal achieve the highest BLEU scores (~70+ and ~60+) due to closer lexical proximity to SCB.

Regional POS Tagger

The run_pos_tagger() function loads a pre-trained BiLSTM model for the selected dialect and returns a prediction function. Supported POS tags are: বিশেষ্য (Noun), সর্বনাম (Pronoun), ক্রিয়া (Verb), বিশেষণ (Adjective), অব্যয় (Adverb).

Signature

PYTHON
predict_func, encoder, model = run_pos_tagger(
    column_name="Mymensingh",   # dialect key
    train=True                   # load pre-trained weights
)

Parameters

column_namestrDialect region key (must match AREA_MAPPING)
trainboolSet True to use the shipped pre-trained model

Basic POS Tagging

PYTHON
from brnltk import run_pos_tagger

predict_func, _, _ = run_pos_tagger(
    column_name='Mymensingh',
    train=True
)

sentence = "তুমি কেমন আছ"
result   = predict_func(sentence, return_confidence=True)

for word, tag, conf in result:
    print(f"{word:<15} --> {tag:<12} (confidence: {conf:.2f})")
output
তুমি --> সর্বনাম (confidence: 1.00)
কেমন --> বিশেষণ (confidence: 1.00)
আছ --> ক্রিয়া (confidence: 1.00)

Tag Multiple Sentences in a Loop

PYTHON
sentences = [
    "আমি বাজারে যাই",
    "সে ভালো মানুষ",
]

for sent in sentences:
    tagged = predict_func(sent, return_confidence=False)
    print(sent, "→", [(w, t) for w, t in tagged])
⚡ Performance Note Call run_pos_tagger() once per session and reuse the returned predict_func. Reloading the BiLSTM model on every prediction is slow.

Stemmer

The stemmer strips common Bangla grammatical suffixes (verb endings, plural markers, possessive endings, emphasis markers) to return the base root form. It is rule-based and requires no training.

stem_sentence — full sentence

PYTHON
from brnltk import stem_sentence

sentence = "ছেলেটি ভাত খাচ্ছে"
stemmed  = stem_sentence(sentence)
print("Stemmed:", stemmed)
output
Stemmed: ছেল ভাত খা

Stem individual words

PYTHON
from brnltk import word_tokenize, stem_sentence

words   = word_tokenize("ছেলেটি খেলাধুলা করছিল")
stemmed = [stem_sentence(w) for w in words]
print(list(zip(words, stemmed)))
📌 Use Case Run stemming before similarity checking or text classification to normalize dialectal word variation across regions.

Tokenizer

The tokenizer splits Bangla text into word tokens while correctly handling Unicode punctuation, danda (।), and whitespace. Use it as a preprocessing step before translation, POS tagging, or stemming.

word_tokenize

PYTHON
from brnltk import word_tokenize

text   = "আমি ভাত খাই এবং কাজ করি।"
tokens = word_tokenize(text)
print("Tokens:", tokens)
output
Tokens: ['আমি', 'ভাত', 'খাই', 'এবং', 'কাজ', 'করি', '।']

Tokenize then Tag

PYTHON
from brnltk import word_tokenize, run_pos_tagger

predict_func, _, _ = run_pos_tagger('Barishal', train=True)

text   = "সে বাজারে গেছে"
tokens = word_tokenize(text)
tagged = predict_func(' '.join(tokens), return_confidence=True)

for w, t, c in tagged:
    print(f"  {w} → {t} ({c:.0%})")

Similarity Checker

The overall_similarity() function computes a semantic similarity score between two Bangla sentences using TF-IDF vectorization combined with N-gram cosine similarity. Score ranges from 0.0 (no overlap) to 1.0 (identical).

Basic Usage

PYTHON
from brnltk import overall_similarity

s1 = "আমি আজ স্কুলে যাই"
s2 = "আমি স্কুলে যাচ্ছি আজ"

score = overall_similarity(s1, s2)
print(f"Similarity Score: {score:.2f}")
output
Similarity Score: 0.72

Compare Translations

PYTHON
from brnltk import translate, overall_similarity

original   = "আমি ভাত খাই"
translated = translate(original, "General", "Barishal")

score = overall_similarity(original, translated)
print(f"Semantic Drift: {1 - score:.2%}")
Score Interpretation 1.0 = identical  |  ≥0.8 = highly similar  |  0.5–0.8 = related  |  <0.5 = divergent

Troubleshooting

ModuleNotFoundError: No module named 'brnltk'

BASH
# Make sure you're in the correct Python environment
$ which python         # or: python --version
$ pip install brnltk   # reinstall

KeyError on dialect name

PYTHON
# WRONG
translate(sentence, from_area="chattogram", ...)   # lowercase → KeyError

# CORRECT
translate(sentence, from_area="Chittagong", ...)   # exact key

Model Warning on first POS load

warning (expected — safe to ignore)
WARNING:absl:Compiled the loaded model, but the compiled metrics have yet to be built. `model` object...

This is a Keras/TensorFlow version mismatch warning. It does not affect predictions. Suppress it with:

PYTHON
import os
os.environ["TF_CPP_MIN_LOG_LEVEL"] = "3"  # before importing brnltk
import brnltk

Slow first prediction

The BiLSTM model is loaded on the first call to run_pos_tagger(). Subsequent calls in the same session reuse the loaded model and are fast. Cache the predict_func variable.
